## Overview

### The challenge

Build a responsive article preview component that matches the provided design for mobile and desktop. The component should include an author block and a share icon that reveals a small share menu with social icons when activated.

Users should be able to:

- View the optimal layout for the component depending on their device's screen size
- See the social media share links when they click (or keyboard-activate) the share icon

## My process

### Built with

- Semantic HTML5
- CSS (custom properties, Flexbox and Grid)
- JavaScript (DOM manipulation for the share menu)
- Mobile-first responsive approach

### What I learned

- Implementing an accessible interactive element: the share button supports keyboard activation (Enter / Space) and closes when clicking outside.
- Positioning a small popup menu above a button using absolute positioning and transform trickery to keep it centered.
- Fine-tuning spacing, shadows and sizes to match the reference images.

### Continued development

- Improve pixel-perfect matching (font sizes, letter spacing and exact spacing values) using design inspection tools.
- Add unit or visual regression tests to ensure future changes don't affect the final look.
